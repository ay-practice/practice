# Cardiology CPD Labs — free prototype

This is a separate prototype and does not modify the original Cardiology Practice site.

## Run locally
Open `index.html` in a modern browser. No build step, server, API key or paid service is required.

## What works
- Animated heart/ECG hero and responsive layout
- Demo research records with search and filters
- Browser-local saved reading list
- Structured evidence-brief template from pasted text
- Browser-native text-to-speech (availability/voice depends on browser/device)
- Slide outline generator and copy-to-clipboard

## Important limitations
- Demo papers are illustrative, not real citations or live journal content.
- The evidence brief is a template, not an AI summary or clinical appraisal.
- Slide output is an outline, not a PowerPoint file.
- No live feed, guideline monitoring, server sync, user accounts or paid APIs are connected.
- Nothing in this prototype should be treated as clinical advice.

## Hosting
Can be deployed as a separate GitHub Pages site from a new repository, keeping the original repository/site untouched. Do not add API keys to frontend files.
